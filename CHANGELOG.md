# Changelog

## v1.11.1

- Cleaned dedicated family box names.
- Removed workflow suffixes such as `TO-BE` / `BR` from single-family physical box names.
- Single-family boxes now use only the Pokémon / evolution-family name.

## v1.11

- Added stable max-overlap physical-box assignment.
- Rebuilding the Organizer now minimizes repeat moves instead of shifting every later logical box.
- Organizer logs how many Pokémon are already in place.
- Box rename logic now follows the actual physical boxes selected by the stable assignment.

## v1.10

- Unified Cleaner, Specials, Dex Tasks, Breeding Setup and Organizer into one floating panel.
- Persistent top navigation and active view.
- Shared draggable/minimizable shell.
